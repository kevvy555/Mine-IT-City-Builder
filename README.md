# MineIT City Builder

Dedicated repository for the MineIT city-builder game set on Koplin 3, centred on Concordia.

## Current phase

The project is currently in **pre-implementation specification**.

The full specification catalogue lives at:

- [docs/specification/README.md](docs/specification/README.md)

## MineIT Universe canon

The city-builder consumes canonical lore and world data from:

- https://github.com/kevvy555/MineIT-Universe

MineIT Universe remains the source of truth for Koplin lore, worlds, organisations, species, materials and the Koplin 3 atlas. This repository owns the city-builder game specification, implementation planning, code and game-specific mutable data.
